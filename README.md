## 📁 About This Repository

This repository contains my one-page developer portfolio. Its visual system combines a warm paper canvas, monospace navigation, cobalt controls, and restrained software-interface details.

### Built With

- React 19 and TypeScript
- Vite
- Tailwind CSS 4
- Motion for subtle interface animation
- Lucide React for icons

### Run Locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

### Updating Portfolio Content

Most editable content lives in [`src/data/portfolio.ts`](src/data/portfolio.ts), including profile details, experience, projects, technology groups, strengths, and social links.

Project presentation is handled by [`src/components/ProjectIndex.tsx`](src/components/ProjectIndex.tsx). The downloadable CV is stored at [`public/Marc-Angelo-Mendoza-CV.pdf`](public/Marc-Angelo-Mendoza-CV.pdf).

<details>
<summary><strong>Project structure</strong></summary>

```text
src/
  components/   Reusable UI and portfolio modules
  data/         Editable portfolio content and TypeScript interfaces
  hooks/        Scroll-aware navigation behavior
  sections/     One-page portfolio sections
  App.tsx       Page composition
  App.css       Visual system and responsive layouts
```

</details>
